
# Week 2 – Responsive Web Design

## Project Name
Saffron Table – Modern Restaurant Website

## Project Overview
This project focuses on developing a responsive restaurant website using HTML5 and CSS3. The website provides a modern dining experience with a professional layout and a clean visual design.

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- CSS Media Queries

## Website Sections
- Navigation bar
- Hero section
- Restaurant introduction
- Specialities and menu
- Contact section and footer

## Responsive Design
The website was tested at three viewport widths:

- Desktop: 1440px
- Tablet: 768px
- Mobile: 400px

CSS media queries were used to adjust the navigation, typography, spacing and menu layout for different screen sizes.
