# Week 5 – Saffron Table SPA Simulation

A small client-side Single Page Application built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Open the `Week-5` folder in VS Code.
2. Open `index.html` with Live Server, or open it directly in a modern browser.
3. Use the navigation to switch between Home, Menu, Our Story, Contact and Reservation.

## SPA features
- Hash-based client-side routes (`#home`, `#menu`, `#story`, `#reservation`, `#contact`).
- DOM content is rendered without reloading the HTML document.
- Browser back/forward navigation works through hash/history events.
- Unknown routes display a 404-style fallback.
- Menu category filters update visible cards without a page reload.
- Reservation form validates required fields and displays a demo confirmation.
- Mobile navigation, keyboard focus styling, semantic landmarks and reduced-motion support.

## Notes
This is a frontend simulation. Reservation requests are not sent to a server and are not stored. Contact/location information is illustrative and should be replaced before real deployment.
