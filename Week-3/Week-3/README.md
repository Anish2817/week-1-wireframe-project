# Week 3 – JavaScript Interactive User Experience

## Project Name
Saffron Table – Interactive Restaurant Website

## Project Overview
This project enhances the Week 2 responsive restaurant website with JavaScript functionality to improve user interaction.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Listeners

## Interactive Features
1. Mobile navigation toggle.
2. Dynamic menu category filtering.
3. Reservation form validation.
4. Email validation.
5. Date validation.
6. Successful form submission message.

## Testing
The website was tested in Chrome using a 400px mobile viewport.
