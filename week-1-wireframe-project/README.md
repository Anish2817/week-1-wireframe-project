# Week 1 — Transforming Wireframes into Static Web Pages

A responsive landing page built with semantic HTML5 and CSS3.

## Files
- `index.html` — page structure and small mobile navigation interaction
- `style.css` — visual styling, layout, and responsive breakpoints
- `REPORT.md` — implementation notes and design decisions

## Run in VS Code
1. Extract the ZIP file.
2. Open the `week-1-wireframe-project` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Resize the browser or use Chrome DevTools device toolbar to test mobile/tablet layouts.

## Technologies
HTML5, CSS3, CSS Grid, Flexbox, media queries, and a small amount of vanilla JavaScript for the mobile navigation toggle.

## Important
No original wireframe image was included with the task details provided here. This project uses an original sample landing-page layout as a practical starting point. If your internship provides a specific wireframe, adjust the sections, dimensions, colors, typography, and spacing to match that reference before submitting.
